01

Factorial

Multiply every positive integer from 1 through n. This recursive version uses 0! = 1 as its base case.

factorial.pyPYTHON
def factorial(n):
    if n < 0:
        raise ValueError("n must be non-negative")
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120
02

Fibonacci sequence

Build a list where each number is the sum of the previous two. The function returns exactly the requested number of terms.

fibonacci.pyPYTHON
def fibonacci(count):
    if count < 0:
        raise ValueError("count must be non-negative")

    sequence = []
    first, second = 0, 1
    for _ in range(count):
        sequence.append(first)
        first, second = second, first + second
    return sequence

print(fibonacci(7))  # [0, 1, 1, 2, 3, 5, 8]
03

Structure to dictionary

A Python dataclass gives a clear structure for related values. asdict() converts its fields into a regular dictionary.

structure_to_dictionary.pyPYTHON
from dataclasses import asdict, dataclass

@dataclass
class Student:
    name: str
    year: int
    course: str

student = Student("Ananya", 2, "BTech")
student_data = asdict(student)

print(student_data)
# {'name': 'Ananya', 'year': 2, 'course': 'BTech'}
