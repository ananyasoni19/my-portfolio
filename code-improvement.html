Messy Code, Made Clear.

A small refactor example: same result, clearer intent, and a reusable function.

BEFORE

A hard-to-follow version

The work is mixed together at the top level, and short variable names hide what the values mean.

messy_version.pyPYTHON
x=[3,7,2,9,10]
z=0
for a in x:
 if a%2==0:
  z=z+a
print("total",z)
AFTER

A clearer version

Names describe their purpose, the calculation is isolated in a function, and the result is returned for reuse.

improved_version.pyPYTHON
def sum_even_numbers(numbers):
    """Return the sum of even numbers in a collection."""
    even_numbers = [number for number in numbers if number % 2 == 0]
    return sum(even_numbers)

values = [3, 7, 2, 9, 10]
even_total = sum_even_numbers(values)
print("Sum of even numbers:", even_total)  # 12

What improved?

  • Clear names: values, number, and even_total explain what each value represents.
  • Reusable function: the calculation can work with any list, not just one hard-coded collection.
  • Built-in sum: Python handles the accumulation, reducing manual state and loop logic.
  • Helpful docstring: a short description explains the function’s job.
